**🔎 Nmap Vulnerability Scanner (Python)**

A simple Python-based vulnerability scanner built using the Nmap library.
This tool runs Nmap vulnerability scripts to detect potential security issues on a target host or network.
It performs service detection and vulnerability scanning using Nmap's built-in scripts.
This project is useful for cybersecurity learners, ethical hackers, and network security testing.

**Features**

Scan a target IP address, hostname, or network range

🛡 Run Nmap vulnerability scripts

⚙ Perform service version detection

⚡ Faster scanning using Nmap timing templates

🎯 Optional custom port scanning

**🧰 Tech Stack**

Language: Python

Library: python-nmap

**Tool: Nmap**

1️⃣ Install Nmap

**Download and install Nmap:**

https://nmap.org/download.html

Check installation:

nmap --version

**2️⃣ Install Python Library**

pip install python-nmap

**3️⃣ Clone Repository**

git clone https://github.com/rajesh0125/vuln-scanner.git

cd vuln-scanner

**⚠️ Disclaimer**
This tool is created for educational and ethical security testing only.
Only scan systems that you own or have permission to test. Unauthorized scanning may violate cybersecurity laws.
